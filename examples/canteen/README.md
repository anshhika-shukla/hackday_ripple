# Campus canteen (RIPPLE live-demo project)

A small ordering app for a college canteen: menu, cart, student discount, GST, loyalty points,
stock and end-of-day reports. 8 modules, 44 tests. Made for showing RIPPLE live: edit a line,
run RIPPLE, and it runs only the tests that change can break.

Set up once from the RIPPLE repo: `bash scripts/setup_demo_project.sh` (copies this folder to
`targets/canteen`, makes it a git repo and builds its Graphify code map).
