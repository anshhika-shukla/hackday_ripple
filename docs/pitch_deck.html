🌊 RIPPLE

Run the tests that matter. Offline change-impact & test-selection agent.

Tagline

"Run ~10% of your tests. Catch the bug anyway. Fully offline."

The Problem: The Slow-Suite Dilemma

Developers face an unpalatable choice on every push.

Option A: Wait for the Full Suite

  • Full test suites take minutes or hours to complete.
  • Destroys developer flow and wastes limited CI quotas.
  • Impossible to iterate quickly on local laptops.

Option B: Skip Running Tests

  • Regressions leak directly into staging or production.
  • Small semantic changes break distant callers silently.
  • Cloud CI tools require expensive hosted APIs and internet.

Architecture & Data Flow

Deterministic graph safety fused with open-weight local LLM intelligence.

git diff → diffmap.py (AST functions) → Graphify graph.json → impact.py (Reverse BFS)
  → Ollama Qwen3 (Risk triage & rank) → Reciprocal Rank Fusion + Guardrails (G1–G5)
  → runner.py (Pytest subset, G6 isolated) → Developer Brief & Offline SVG Ripple Map

Deterministic Guardrails

  • G1 (Safe Mode): LLM can never drop candidate tests.
  • G2 (AST Skip): Skip-all allowed only on proven AST equivalence.
  • G4 (Fail-Safe): Malformed LLM output defaults to graph ranking.

Local & Offline

  • Model: Qwen3 (4B / 1.7B) via Ollama on localhost.
  • Graphify: Code-only extraction (tree-sitter, zero API keys).
  • Air-Gapped: Validated with Wi-Fi switched off. Zero CDN.

Empirical Benchmark & Ablation

Evaluated against 30 deterministic AST mutants (seed 1337).

Innovation & Stretch Features

Taking test selection beyond traditional tools.

Autonomous Test Synthesis (`ripple draft-tests`)

  • Detects modified functions lacking test coverage in the graph.
  • Local LLM synthesizes targeted regression pytests.
  • Guardrail: Synthesized tests must pass on pre-change baseline before adoption.

Zero-Dependency Visual Map

  • Self-contained HTML/SVG visualization (ripple_map.html).
  • Color-coded impact radius (Red = Changed, Amber = Callers, Green = Selected).
  • Tested directly on 2-meter projector view distance.
